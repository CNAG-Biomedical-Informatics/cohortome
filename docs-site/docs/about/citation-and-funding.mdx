# Citation, Collaborators, And Funding

## Project

COHORTome is open-source software developed by Manuel Rueda
at CNAG for clinical and multimodal research with controlled data access.

COHORTome is a generic tool whose first consortium-scale deployment is planned in the
context of [3TR](https://www.3tr-imi.eu/). It is intended to support 3TR-wide
analysis as authorized datasets are released, while remaining reusable outside
the consortium. The first real dataset use case uses PRECISESADS data from the
3TR Omics DM Warehouse with collaborators at Fundacion Publica Andaluza Progreso
y Salud (FPS) in Granada.

## Citation

A software/platform manuscript with a PRECISESADS translational use case is in
preparation. Until a formal citation is available, cite the software repository
and the exact version or commit used for an analysis.

- [COHORTome repository](https://github.com/mrueda/cohortome)
- [Apache License 2.0](https://github.com/mrueda/cohortome/blob/main/LICENSE)

Published work must distinguish the open-source application and synthetic
fixtures from restricted PRECISESADS or 3TR data.
