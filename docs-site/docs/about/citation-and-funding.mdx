## Project

COHORTome is a generic tool whose first consortium-scale deployment is planned in the
context of [3TR](https://www.3tr-imi.eu/). It is intended to support 3TR-wide
analysis as authorized datasets are released, while remaining reusable outside
the consortium. The first real dataset use case uses PRECISESADS data from the
3TR Omics DM Warehouse with collaborators at Fundacion Publica Andaluza Progreso
y Salud (FPS) in Granada.
