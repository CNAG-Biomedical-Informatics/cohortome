# API reference

[Open the ReDoc API reference](/api/) to browse endpoints, request parameters,
and response schemas.

The documentation site uses a checked-in
[OpenAPI snapshot](/openapi/cohortome-openapi.json). For the exact API of a
running installation, use these paths on that installation:

| Path | Contents |
| --- | --- |
| `/openapi.json` | OpenAPI schema |
| `/redoc` | ReDoc reference |
| `/docs` | Swagger UI |

Some Query, Analysis, and Pheno-Ranker result payloads have flexible response
schemas. Access controls still apply to API calls.
